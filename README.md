# Telegram-бот управления чатами (модерация + автосохранение контента)

Классический Telegram-бот на [aiogram 3.x](https://docs.aiogram.dev) с двумя блоками:

- **Модерация чатов** (аналог ExeControl): бан/кик/мут/размут, удаление сообщений, закреп, флуд-защита, приветствия.
- **Автосохранение контента** (аналог RipSave): бот копирует медиа из чатов, где он состоит, в архивный канал и/или качает файлы на диск.

> Бот сохраняет только тот контент, к которому у него есть доступ как у участника/админа. Массовый дамп закрытых чужих чатов не поддерживается.

## Установка

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Создайте бота в [@BotFather](https://t.me/BotFather) (`/newbot`) — получите токен.
2. Узнайте ваш числовой ID (у `@userinfobot` или командой `/id` после запуска).
3. Скопируйте `.env` и заполните:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_IDS` — ваш ID (через запятую, если несколько);
   - `ARCHIVE_CHAT` — куда копировать сохранённый контент (канал);
   - `SAVE_TYPES`, `FLOOD_*`, `WELCOME_*`, `SAVE_TO_DISK` — по желанию.

## Запуск

```bash
python main.py
```

## Как пользоваться

### Модерация (в группе, бот — администратор)

| Команда (отвечая на сообщение) | Действие |
|---|---|
| `/ban` | бан пользователя |
| `/unban` | снять бан |
| `/kick` | исключить пользователя |
| `/mute 30` | мут на 30 минут (по умолчанию 10) |
| `/unmute` | снять мут |
| `/clear` | удалить сообщение-ответ |
| `/pin` / `/unpin` | закрепить / открепить сообщение-ответ |
| `/id` | показать ID вас и чата |

### Автосохранение (RipSave)

- `/watch @username` — добавить чат/канал в автосохранение.
- `/watch` (в самой группе) — добавить текущий групповой чат.
- `/unwatch`, `/watchlist` — управление списком.
- Настроить `ARCHIVE_CHAT` (канал для копий) и/или `SAVE_TO_DISK` (папка для файлов).

Бот копирует медиа (фото, видео, документы, аудио, голосовые, GIF) из отслеживаемых чатов в архивный канал, добавляя подпись с именем автора. При `SAVE_TO_DISK` также качает файлы в папку по датам.

## Структура

```
main.py        — точка входа, команды, маршруты
config.py      — настройки из .env
moderation.py  — бан/кик/мут/закреп/удаление
antispam.py    — флуд-контроль и приветствия
saver.py       — автосохранение контента
```

## Ограничения

- Бан/мут/удаление требуют прав администратора группы.
- Для копирования в `ARCHIVE_CHAT` этот чат должен принимать от бота сообщения (бот админ).
- Список `watchlist` в этом примере в памяти — при перезапуске сбросится. Для постоянного хранения подключите SQLite/Redis или файл.
